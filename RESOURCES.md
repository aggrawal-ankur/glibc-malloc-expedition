# Resources

These are the resources that I have used in my expedition.

1. [The official glibc repository.](https://sourceware.org/git/glibc.git)

2. [An unofficial glibc mirror on GitHub.](https://github.com/bminor/glibc) It is no longer managed since January 2026, though. But it really provides a great interface to access the repository on web. The sourceware interface is a little hard to navigate.

3. [A collection of dlmalloc source code, starting from v2.5.x up to v2.8.6.](https://github.com/DenizThatMenace/dlmalloc/) It is great for checking historical things.
